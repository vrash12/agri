# Bicol Region planning/reference geofences

Status: prepared for the explicit Bicol release on September 23, 2026. The reviewed snapshot contains **114 active planning references**: 107 municipalities, six component/independent cities in the six Bicol provinces, and Naga City as a separate highly urbanized city scope. The import and Region V membership are explicit maintenance actions; they are excluded from DatabaseSeeder and do not create accounts.

## Coverage and ownership

BicolBoundarySeeder runs the seven province/city seeders in one outer transaction. It creates only missing active Province, Municipality, Boundary and attributed audit rows. It does not create Regional Heads, Super Administrators, staff, farmers, parcels, or other operational records. Existing IDs, assignments, boundaries, styles, and audit history are preserved on a repeat run. Conflicting province ownership, inactive workspaces, changed active references, overlaps, checksum errors, or a late failure roll the complete Region V import back.

All 114 source features were checked with Shapely 2.1.2 and the application GeoGeometry validator. Every source interior point matched exactly one source polygon and the supervising province. Computed application areas differ from the COD-AB polygon references by 0.0052%–2.5393%, within the importer’s 3% rejection threshold. Government datasets may share upstream mapping, so this is an independent dataset check rather than a legal survey.

These are approximate planning/reference boundaries, not legal, cadastral or survey-grade boundaries. Obtain LGU/NAMRIA verification before official boundary decisions. Inclusion in AgriGOV does not settle jurisdiction, title, municipal waters or other legal questions.

## Explicit installation

No migration, runtime package, API key, or frontend asset is required. Existing province, municipality, boundary, region and audit schemas must already be installed. After a verified private backup, deploy the reviewed code using GitHub push followed by Hostinger git pull --ff-only origin main, then run only:

    php artisan db:seed --class=BicolBoundarySeeder --force
    php artisan region-access:configure --owner=<active-owner-id> --region=region5

For an all-or-nothing release, execute both the explicit boundary seeder and RegionSupervision::configure($owner, region5) inside one database transaction. The command links Albay, Camarines Norte, Camarines Sur, Catanduanes, Masbate, Sorsogon and the separate Naga City scope. It does not issue a Regional Head or provincial account. Refresh config, route and view caches after verification. Never run legacy migrations or DatabaseSeeder for this addition.
