Missing information and duplicate review

Use Dashboard attention links and the Farmers registry filters to review missing FFRS references, missing farm locations and farmers without saved parcels. An empty location or the importer value UNKNOWN means the location needs review, not that a field address was verified. A missing measurement or registry reference is not zero or proof of ineligibility. Check approved office source records before correcting the original form.

Farmer and assistance imports match records within the owning municipality, including recorded FFRS/RSBSA references when the workflow supports them. Validation errors identify fields or Excel rows to correct in the source workbook. A failed validated import must not be treated as completed. Imported source rows and canonical farmer profiles have distinct purposes; repeated parcel-address rows do not automatically mean separate people.

Assistance duplicate checks warn about earlier releases of the same input to the same farmer in the relevant recorded season/year or date window. A warning requires review, not an automatic fraud finding or refusal. A legitimate separate entitlement can need explicit officer confirmation in the original release form. Do not invent a season from a receipt date or bypass duplicate review.

Related farmers, cooperatives, machinery and releases must keep municipality ownership consistent. If a stale-edit message appears, reload and review the latest record. The Assistant explains these rules and may show supported current missing-reference counts; it cannot deduplicate the database, correct fields, decide eligibility or certify real delivery.
