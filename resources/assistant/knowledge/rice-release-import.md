Importing rice seed releases

In Agriculture & Fisheries, open the rice releases register and choose Import rice releases. Choose the authorized municipality that owns the imported rows, then upload an NRP .xlsx or .xls workbook. The system validates the workbook before inserting new distributions or updating matching records.

If validation fails, read the displayed Excel row and field, correct that cell in the original workbook and upload it again. Failed validation imports or updates no rows. Lot Series supports up to 10,000 characters through the deployed TEXT field; seed varieties and sowing labels allow 120 characters. An error for a different field still requires correcting that field. Duplicate releases can require explicit review and confirmation.

Do not bypass validation or duplicate review. For a server error, give the administrator the module, action and non-sensitive error message. Do not paste real rows or credentials into chat. The Assistant cannot inspect, upload or import the workbook and cannot confirm an import completed.
