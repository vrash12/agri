Protected Backup Folder files

Backup Folder is a private office document repository, not an automatic database-backup scheduler. Municipal staff and heads use their own municipality's files; provincial agriculture staff work within their assigned province. System Owner, Regional Head, Super Admin and veterinary accounts do not gain access to these protected files.

Authorized staff upload one or more approved documents through the original upload form, choosing the owning municipality when required. Each file is limited to 50 MB. Browser-executable and program files, including HTML, SVG, JavaScript, PHP and EXE, are refused. Use the displayed folder-name rules and correct any validation error. Filename, folder, date, uploader, extension and size filters help find permitted files.

Supported PDF, image, text, spreadsheet and document types have authorized previews. Other stored types download instead of executing inside the page. Authorized text-like files and XLSX workbooks can be edited through their supported original editor; saving recalculates file size and hash. Deleting a file removes the stored file as well as its record, so use the original confirmation workflow.

The Assistant can explain file handling. It cannot open private uploads, read their contents, send them to OpenAI, edit them, download them or create a database backup. Missing access requires review by the responsible administrator, not a request to bypass ownership rules.
