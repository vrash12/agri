Farmer profiles and workbook imports

Open Farmers to see the permitted registry and Parcel map. Location filters select the account's authorized region/province/municipality without granting broader access. Registry search and follow-up filters refine listed profiles; parcel maps retain their stated workspace coverage. To view one person, open their record or ask the Assistant to find a farmer by name or complete registry ID.

Authorized operational staff choose Add farmer and complete Add farmer profile, reviewing the owning municipality and recorded details before Create farmer. First and last names are required. Enter only verified registry references and measurements. Assistance and parcels are added through their own workflows after the profile is saved. To correct an existing profile, open its permitted edit form; an outdated-record message requires reloading the latest version. Oversight roles do not make routine profile edits.

Import farmer registry from Excel accepts the supported RSBSA/FFRS workbook through the original import form, including PARCEL LISTING and OUTSIDE LGU sheets. XLSX/XLS uploads are limited to 10 MB. Provincial agriculture staff must select an authorized municipality; municipal staff remain in their own. Matching registry identifiers can update existing profiles; new valid records create profiles, and blank/invalid rows can be skipped. Review the import outcome rather than assuming every workbook row was accepted. Retained source rows and parcel addresses do not replace verified canonical identity fields. The Assistant cannot inspect the workbook, import it or save a profile.
