Assistant AI technology and retrieval

The eAgriLGU Assistant is an AI-assisted software guide integrated into the application. eAgriLGU uses PHP 8.3+, Laravel 12, MySQL/MariaDB, Blade and JavaScript. General software help uses the Laravel AI SDK with OpenAI. The configured default model is the pinned GPT-4.1 mini snapshot gpt-4.1-mini-2025-04-14. This integrated feature is distinct from the ChatGPT website and is not a person or a government decision-maker.

Identity, greetings and basic capability/technology explanations can be answered locally without a provider request. For documented software help, the application resolves a supported eAgriLGU topic locally and retrieves role-eligible, reviewed passages with lexical BM25 ranking. This is retrieval-augmented generation, or RAG. That path sends an application-owned canonical question and reviewed evidence, not the raw question or visible chat. Structured output and application checks validate reply format and allowed references; references do not prove every statement is correct.

The Assistant covers eAgriLGU features rather than unrelated general chat, public web research or arbitrary writing requests. Follow-ups can reuse a reviewed help topic or authorized local record reference; the complete conversation is never provider history. Operational record requests and replies remain inside the application.

Supported operational summaries are fresh authorized database reads inside eAgriLGU, rather than model guesses. Accepted documented help can be cached for ten minutes; private operational answers are not cached as AI help. The system uses no vector database, autonomous write tools, web search or whole-repository ingestion. Developers review code and maintain curated passages; the model does not read source directories or private uploads at runtime. Failed documented generation can fall back to saved guidance. AI can make mistakes; important work should be checked in the original permitted module and its records.
